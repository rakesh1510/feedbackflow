FeedbackFlow v4 (full project)

This package includes the full project, keeping v3 features and adding v4 upgrades.

Included features
- Landing page, pricing page, register/login/logout
- Dashboard with summary cards
- Projects page
- Create, edit, delete projects
- Widget install snippet + copy button
- Allowed domain verification
- Optional alert email per project
- Feedback list with filters and search
- Analytics page with rating breakdown and trend table
- Widget settings per project:
  - button text
  - button color
  - left/right position
- API endpoint for feedback submit
- Config template only (config.php is intentionally excluded)

Important
- Create your own includes/config.php on local and VPS
- Do not commit config.php
- Import the SQL in sql/schema.sql
